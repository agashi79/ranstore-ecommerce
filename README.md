# Ranstore E-commerce 🛍️

Website toko online lengkap dengan panel admin untuk mengelola katalog produk, keranjang belanja, dan sistem pemesanan.

## Fitur Utama

### Untuk Customer
- 🏠 Halaman Beranda dengan katalog produk
- 🛒 Keranjang Belanja
- 📦 Katalog Produk dengan kategori
- 📋 Cara Pemesanan
- ℹ️ Halaman Tentang Toko
- 👤 Profil Pengguna (nama, alamat, email, password)
- ⚙️ Pengaturan Akun
- 📞 Kontak WhatsApp (081519992955)

### Untuk Admin
- 📊 Dashboard Admin
- 🖼️ Edit Banner (foto + teks)
- 📷 Manajemen Foto Produk (max 12 foto)
- 🎬 Upload Video Produk (1 video)
- 📝 Edit Nama & Deskripsi Produk
- 📊 Manajemen Stok Barang
- 🗂️ Manajemen Katalog
- 👥 Kelola Pesanan

## Tema
- 🌙 Tema Gelap & Tajam
- ✏️ Ikon Edit Kecil di setiap area
- 🖼️ Foto Placeholder untuk semua gambar

## Setup & Instalasi

```bash

npm run dev

# Production
npm run build
npm start
```
